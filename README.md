#  Proyecto Final - Programación III  
## Sistema Web de Librería Online

Este proyecto consiste en el desarrollo de un sistema web que permite a los usuarios consultar información sobre libros y autores, así como enviar mensajes mediante un formulario de contacto.  

El sistema fue desarrollado aplicando buenas prácticas de desarrollo web y validado mediante pruebas automatizadas.

---

##  Tecnologías utilizadas

- HTML  
- CSS  
- JavaScript  
- PHP  
- MySQL  
- Selenium WebDriver (C#)  
- Visual Studio Community  
- GitHub  
- Jira  

---

##  Funcionalidades principales

- Inicio de sesión (login de usuarios)  
- Visualización de libros  
- Visualización de autores  
- Búsqueda de libros  
- Consulta de libros por autor  
- Formulario de contacto con validaciones  
- Navegación entre páginas  
- Cierre de sesión

##  Pruebas automatizadas

El proyecto incluye pruebas automatizadas desarrolladas con Selenium WebDriver en C#, las cuales permiten validar el funcionamiento del sistema simulando el comportamiento de un usuario real.

Funcionalidades probadas:
- Inicio de sesión  
- Búsqueda de libros  
- Navegación del sistema  
- Envío de formularios  

 Código de pruebas automatizadas:
